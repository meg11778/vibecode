What each seat is worth, by round size

Average result per hand in dollars at $1 a point, each player paid their points less the table's average. The first seat bids first and leads; the dealer bids last and may not make the bids add up to the number of tricks. The same bots sit in every seat, so any difference is the seat and how well the bots use it.
